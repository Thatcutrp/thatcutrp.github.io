# ThatCutRP Portfolio

A modern, responsive project showcase website built with HTML, CSS, and JavaScript.

## Features

- 🎨 Modern dark theme with gradient accents
- 📱 Fully responsive design
- ✨ Smooth animations and transitions
- 🚀 Fast and lightweight
- 🔗 Easy to customize

## Customization

### Update Your Projects

Edit the project cards in `index.html` under the Projects section:

```html
<div class="project-card">
    <div class="project-icon">🚀</div>
    <h3>Your Project Title</h3>
    <p>Your project description</p>
    <a href="https://your-project-url.com" class="project-link">View Project →</a>
</div>
```

### Change Colors

Edit the CSS variables at the top of `styles.css`:

```css
:root {
    --primary-color: #6366f1;      /* Main accent color */
    --secondary-color: #ec4899;    /* Secondary accent */
    --bg-dark: #0f172a;            /* Dark background */
    --bg-darker: #020617;          /* Darker background */
}
```

### Update Social Links

Edit the contact section in `index.html` to add your social media links.

## Deployment

Your site is automatically deployed to GitHub Pages at: `https://thatcutrp.github.io`

Just push changes to the `main` branch and they'll be live in minutes!
